# 自作PC予算計算ツール

価格.comの最安価格をもとにしたパーツデータから、自作PCの構成パターンごとの合計金額を計算するツールです。Python版とWeb版があります。
パーツデータは175品目(CPU / CPUクーラー / マザーボード / メモリ / GPU / SSD / 電源 / ケース / OS)。

## できること

- 構成パターン(AM4コスパ / VRChat向けAM4強化 / AM5バランス / AM5 VRChat本気 / Intel入門)の内訳と合計を表示
- 予算を入力すると、予算に収まるパターンと残額を表示
- パーツ一覧の表示
- カスタム構成モード: カテゴリごとにパーツを1つずつ選んで合計を計算
- 互換性チェック: ソケット不一致、メモリ規格(DDR4/DDR5)の不一致、内蔵GPUなしCPUでGPU未選択、クーラー別売りCPUでクーラー未選択、ATXマザーボードとMicroATX専用ケースの組み合わせを警告
- 性能見積もり: PassMarkスコア(CPUシングル/マルチ、GPU G3D Mark)から性能クラスを表示し、CPUボトルネックなどのバランス判定とVRChat目安も出す(スコアは2026-11-23時点の目安)
- 購入リンクまとめ: 構成が決まったら、各パーツの価格.com / Amazon検索リンクを一覧表示(Web版はボタン、Python版は結果表示に含む)
- 新品/中古フィルター: カスタム構成で価格の種類を切り替えられる。中古相場データがあるパーツは中古価格で計算でき、RX 580のように新品取扱いがないパーツは中古専用パーツとして収録(中古相場はメルカリの売り切れ価格を調査したもの)

## 使い方

```bash
python pc_budget.py
```

メニューが出るので、番号を入力して選ぶだけです。

## ファイル構成

- `pc_budget.py` … 本体プログラム
- `parts.csv` … パーツデータ(カテゴリ、名前、価格、ソケット、メモリ規格、備考)

## 価格データについて

- 価格は **2026年11月23日時点** で価格.comの最安価格を調べたものが基準です(税込)。
- PCパーツの価格はすぐ変わるので、使うときは価格.comで最新価格を確認して `parts.csv` の数字を書き換えてください。CSVを直すだけで計算に反映されます。

## カスタマイズ

- パターンを増やす: `pc_budget.py` の `PATTERNS` に、parts.csv の「名前」を組み合わせて書き足す
- パーツを増やす: `parts.csv` に行を追加する
